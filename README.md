# Tripleten web_project_around_es

# SPRINT 9

Proyecto del bootcamp de Desarrollo Web de TripleTen.  
Página interactiva con tarjetas de lugares en EE. UU., donde el usuario puede editar su perfil y gestionar tarjetas dinámicamente.

---

## Funcionalidad

- Editar perfil (nombre y descripción) con validación de formularios
- Agregar nuevo lugar (título + URL) con validación
- Dar “like” a tarjetas
- Eliminar tarjetas
- Abrir imagen en tamaño grande
- Cerrar popups con click en overlay y con la tecla Esc

## Tecnologías

- HTML
- CSS
- JavaScript
